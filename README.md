# Сімейний бюджет

Мобільна веб-апка для ведення домашнього бюджету за методом конвертів.
Дані зберігаються у хмарі (Firebase) і синхронізуються між усіма пристроями в реальному
часі — кожен веде бюджет зі свого телефона. Працює й офлайн: зміни підхопляться, щойно
з'явиться інтернет.

## Можливості

- Декілька користувачів: email + пароль, акаунт створюється при першому вході (Firebase Auth).
- Спільна каса: поповнення (зарплата тощо) та розподіл грошей у конверти.
- Конверти (категорії витрат): створення, іконка та колір, витрати, архівація.
- Місячний бюджет: план на конверт, скільки вже покладено і витрачено, копіювання плану з минулого місяця.
- Звіти: витрати за категоріями та тренд доходи/витрати по місяцях, світла й темна тема.
- Тимчасові перекази між конвертами з нагадуванням про повернення.
- Експорт/імпорт JSON — резервні копії та перенесення даних зі старої localStorage-версії.

## Налаштування Firebase (один раз, ~5 хвилин)

1. Відкрийте https://console.firebase.google.com і створіть проєкт (назва будь-яка,
   Google Analytics можна вимкнути). Безкоштовний тариф Spark — достатній назавжди
   для сімейного використання.
2. **Authentication** → Get started → вкладка **Sign-in method** → увімкніть **Email/Password**.
3. **Firestore Database** → Create database → оберіть регіон (напр. `europe-west3`,
   Франкфурт) → почніть у **production mode**.
4. У Firestore відкрийте вкладку **Rules**, вставте вміст файлу `firestore.rules`
   з цього проєкту та натисніть **Publish**.
5. Project Overview → ⚙ **Project settings** → внизу **Your apps** → додайте **Web app**
   (іконка `</>`), без hosting. Скопіюйте об'єкт `firebaseConfig`.
6. Вставте ці значення у файл `src/firebase-config.ts` замість `REPLACE_ME`.

> **Про доступ:** зараз правила пускають будь-кого, хто зареєструється. Після того як ви
> обидва створите акаунти, рекомендую у `firestore.rules` переключитися на варіант з
> allowlist (закоментований у файлі): впишіть ваші два email і опублікуйте правила ще раз.
> Тоді чужі реєстрації не побачать ваших даних.

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

1. Створіть порожній репозиторій на GitHub.
2. У корені проєкту:
   ```bash
   git init
   git remote add origin https://github.com/USER/REPO.git
   ```
3. Запустіть деплой:
   ```bash
   npm run deploy
   ```
4. На GitHub: **Settings → Pages → Branch: `gh-pages` / root** (зазвичай вмикається автоматично).
5. Апка буде на `https://USER.github.io/REPO/` — відкрийте на телефоні та додайте на
   головний екран (Safari/Chrome → «Додати на початковий екран»).

## Перенесення даних зі старої версії (localStorage)

Якщо ви вже вели бюджет у попередній версії: там у Налаштуваннях зробіть
**Експорт (резервна копія)**, а в новій версії — **Налаштування → Імпорт** і оберіть цей файл.
Всі конверти, операції та бюджети з'являться у спільній базі.

## Стек

Vite + React 19 + TypeScript, Tailwind CSS 4 (тема в стилі shadcn/ui), Font Awesome
(free-solid), Firebase (Auth + Firestore з офлайн-кешем), gh-pages.
